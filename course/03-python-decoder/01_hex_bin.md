같은 숫자를 10진수, 16진수, 2진수로 다르게 적을 뿐입니다. CAN 데이터는 보통 16진수로 보여 주고, 신호는 2진수(비트) 단위로 잘라 읽습니다.

| 10진수 | 16진수 | 2진수 |
|---|---|---|
| 180 | `B4` | `1011 0100` |
| 11 | `0B` | `0000 1011` |
| 255 | `FF` | `1111 1111` |

- 16진수 한 자리는 2진수 네 자리입니다. `B` = `1011`, `4` = `0100` 이므로 `B4` = `1011 0100`.
- **1바이트 = 8비트 = 16진수 두 자리**이고, 값의 범위는 0~255입니다.

| 16진수 | 2진수 | 16진수 | 2진수 | 16진수 | 2진수 | 16진수 | 2진수 |
|---|---|---|---|---|---|---|---|
| 0 | 0000 | 4 | 0100 | 8 | 1000 | C | 1100 |
| 1 | 0001 | 5 | 0101 | 9 | 1001 | D | 1101 |
| 2 | 0010 | 6 | 0110 | A | 1010 | E | 1110 |
| 3 | 0011 | 7 | 0111 | B | 1011 | F | 1111 |

파이썬에서는 이렇게 씁니다.

```python
0xB4                 # 180. 0x로 시작하면 16진수 숫자
int("B4", 16)        # 180. 문자열 "B4"를 16진수로 읽기
format(180, "08b")   # '10110100'. 8자리 2진수 문자열, 빈자리는 0
format(180, "02X")   # 'B4'
```

따옴표로 감싼 `"B4"` 는 **문자열**(글자)이고 `180` 은 **숫자**입니다. 둘은 다른 값입니다.

## 문제

두 함수를 완성하세요.

- `hex_to_int(text)`: 16진수 문자열을 정수로 바꿉니다 (`"B4"` → 180).
- `to_bin8(n)`: 0~255 정수를 8자리 2진수 문자열로 바꿉니다 (180 → `"10110100"`).

```python starter
def hex_to_int(text):
    return int(text, ___)


def to_bin8(n):
    return format(n, ___)
```

## 힌트

1. 16진수는 밑(base)이 16인 수입니다.
2. 형식 문자열 `"08b"` 는 「8자리, 빈자리는 0, b는 2진수(binary)」라는 뜻입니다. 문자열이므로 따옴표를 붙입니다.

## 정답

<details><summary>펼치기</summary>

```python solution
def hex_to_int(text):
    return int(text, 16)


def to_bin8(n):
    return format(n, "08b")
```

</details>

## 확인

```python check
hex_to_int("B4")
hex_to_int("ff")
hex_to_int("0B7A")
to_bin8(180)
to_bin8(5)
to_bin8(hex_to_int("7A"))
```

## 통과 후

비트 실험실의 바이트 칸(16진수)과 비트 격자(2진수)가 바로 이 변환입니다.
