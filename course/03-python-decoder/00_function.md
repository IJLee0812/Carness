이 연습의 답은 모두 **함수**로 씁니다. 함수는 값을 받아 계산한 뒤 결과를 돌려주는 작은 기계입니다.

```python
def double(x):
    return x * 2
```

- `def 이름(입력):` 으로 시작합니다. 줄 끝 콜론(`:`)을 빠뜨리면 문법 오류가 납니다.
- 함수 안의 줄은 **공백 4칸** 들여씁니다. 들여쓴 줄까지가 함수의 몸통입니다. 편집기에서 Tab을 누르면 4칸이 들어갑니다.
- `return 값` 이 함수의 결과입니다. `return` 이 없으면 결과는 `None`(없음)입니다.
- 만든 함수는 `double(21)` 처럼 불러 씁니다. 결과는 `42` 입니다.
- 계산은 `+ - * /`, 거듭제곱은 `**` 입니다 (`2 ** 8` → 256).
- 중간값이 궁금하면 `print(x)` 를 넣으세요. 채점 결과 아래 「출력」에 나옵니다.

## 문제

차속은 CAN에서 보통 km/h로 오지만, 계산은 m/s로 하는 경우가 많습니다. 1 m/s = 3.6 km/h입니다.

km/h를 m/s로 바꾸는 `kmh_to_ms(kmh)` 를 완성하세요. 편집기의 `___` 를 지우고 알맞은 식을 쓴 뒤 **실행·채점**을 누르면 됩니다.

```python starter
def kmh_to_ms(kmh):
    return ___
```

## 힌트

1. km/h에서 m/s로 갈 때는 3.6으로 **나눕니다**.
2. `return kmh / 3.6`

## 정답

<details><summary>펼치기</summary>

```python solution
def kmh_to_ms(kmh):
    return kmh / 3.6
```

</details>

## 확인

```python check
kmh_to_ms(36)
kmh_to_ms(0)
kmh_to_ms(100)
```
