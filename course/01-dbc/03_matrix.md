---
DBC를 사람이 검토할 때는 보통 **통신 매트릭스(CAN matrix)** 라는 표로 봅니다. 신호 하나가 한 행이고, 열에는 채널·메시지·ID·DLC·주기·송신 노드·신호·시작 비트·길이·바이트 순서·부호·factor·offset·범위·단위·수신 노드·값 정의가 들어갑니다.

```widget dbc
vehicle = "rav4_2017"
view = "matrix"
```

## 해 볼 것

1. 검색창에 `km/h` 를 넣어 보세요. 차속과 관계된 신호가 한눈에 모입니다.
2. 「주기 실측(ms)」 열을 보세요. 같은 차속 계열이라도 메시지마다 주기가 다릅니다.
3. 위쪽 **CSV** 버튼으로 내려받아 엑셀에서 열어 보세요. 한글이 깨지지 않게 저장되어 있습니다.

> [!NOTE]
> 터미널에서는 `uv run carness-dbc rav4_2017 -o rav4.csv` 로 같은 표를 만들 수 있고, 다른 `.dbc` 파일 경로를 넣어도 됩니다. `uv run cantools dump 파일.dbc` 는 메시지마다 비트 배치를 글자 그림으로 보여 줍니다.
